Tentang Saya

Saya Petrik Begger, mahasiswa Program Studi Sistem Informasi, Fakultas Teknologi Informasi, Universitas Kristen Satya Wacana (UKSW) Salatiga. Saya berasal dari Ketapang, Kalimantan Barat, dan menamatkan pendidikan terkahir di SMA Pangudi Luhur St. Yohanes ketapang.

Saat ini saya memfokuskan diri pada Cyber Security dan Web Development, sambil terus belajar pemrograman Python, basis data MySQL, dan pembuatan aplikasi web. Pengalaman berorganisasi sejak SMA membentuk kemampuan kepemimpinan, manajemen, dan berbicara di depan umum, yang ingin saya padukan dengan keahlian teknologi untuk menghasilkan karya digital yang bermanfaat.
